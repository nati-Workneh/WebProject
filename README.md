# RECYCLE — Hebrew Recycling Website

A multi-page Hebrew RTL website for a fictional recycling company, built with HTML, CSS, JavaScript, and SCSS.

## Overview

RECYCLE is a static web application showcasing a company that facilitates item recycling in the community. The site is fully right-to-left (RTL) and written in Hebrew.

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Main layout with navigation bar and iframe content frame |
| `home.html` | Homepage |
| `about_company.html` | About the company |
| `how_it_works.html` | Step-by-step process explanation |
| `recycle_background.html` | Background information on recycling |
| `offer_item.html` | Form to submit an item for recycling |

## Tech Stack

- HTML5
- CSS3 / SCSS
- Vanilla JavaScript
- Google Fonts (Varela Round)
- RTL layout (Hebrew)

## Features

- Responsive navigation bar
- Dynamic date & time display
- Iframe-based content navigation
- Full Hebrew language and RTL support
